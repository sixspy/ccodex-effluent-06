# effluent-06 停用排放口禁采样裁决（排污己第 6 槽）

- 裁决日期：**2026-11-25（当日锁死）**
- 适用对象：排放口 **OF-E1-B**，以及一切 `status='停用'` 的排放口
- 锁死口径：本裁决当日不得改道，停用态与采样落库两边**不得混用**，旁门禁止。

## 1. 正确性口径（二选一，不得交叉）

- **甲路径（本槽裁决采用）**：排放口已停用，则采样写口**正式区零增并整笔回退**。
  - `POST /api/samples` 命中停用口：返回 400，不向 `sample_batches` 写任何行，
    该口批次数/行数零增，业务事务整笔回退，口锁不残留。
  - 强写另笔提交一条 `action='停用禁采偏航'` 的审计/裁决痕（独立事务，不随整笔回退丢失）。
- 乙路径（本槽**不采用**，仅备案）：停用口只许写影子挂起批，原子升正且正式区零改，
  否则挂起批作废。

> 两套写法交叉会让停用口仍出正式批，故本槽只实现甲路径，不引入影子/正式双写。

## 2. 争用口锁

- 锁键：`outfall:{outfall_id}`，落 `effluent_locks`，按会话签发唯一 `owner_token`。
- 两路会话同口抢建必须抢同一把口锁：主键原子仲裁，同账号两路会话也不重入。
- 后到者：409、正式区零行，并在独立事务写 `contention_log`（`action='争用失败'`），
  该争用痕不得被请求事务回滚吞掉。
- 停用/启用切换（`POST /api/outfalls/{id}/status`）抢同一把口锁，闭合
  “读到开放后被停用”的交叉窗口。

## 3. 五页同态核销

| 页面 | 同态要求 |
| --- | --- |
| 排放口页 | OF-E1-B“停用”标签与“停用禁采”徽标亮，口径流量清零，可停用/启用 |
| 采样页 | 选中该口即提示拒建并禁用入库；后端同样硬拒；列表显口态 |
| 处理厂页 | PL-EAST-01 下属 OF-E1-B 停用态/拒建与排放口服务同源一致 |
| 对账页 | DP-2026-E01 对账剔除 `SM-OF-E1-B-001`（1200 m3/h），给剔除台账 |
| 总览页 | 停用口计流 `down_outfall_flow_m3h = 0`（清零），另列“已剔除停用流量 1200” |
